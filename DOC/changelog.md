# 版本更新记录

## 0.1.1（2026-09-11）

- 笔记列表、草稿和编辑窗口支持单条删除，确认后持久化并通知其他面板更新。
- 视频脉络改用片段编号定位主题、金句和方法，程序从来源取精确时间及原文；无法核实的个别引用省略并提示，全部主题无效仍报错。
- 面板收起保留名称横条与展开按钮，保留 iframe 状态；页面入口再次点击始终展开，节点脱离页面时重新挂载。
- 支持扩展图标打开当前 YouTube 普通视频面板；新加 scripting 权限用于同一 YouTube 授权范围的脚本恢复，不扩展网站范围。
- 移除展开面板的“学习笔记”标题，显示小号版本；移除常驻本地翻译按钮，首次模型准备若被浏览器要求确认，仅在错误提示内出现“继续准备”。
- 独立阅读增加返回原视频，优先激活原标签；原标签关闭或已切换其他视频时另开来源视频，不覆盖用户正在浏览的页面。
- 构建检查四个 package.json 和扩展 manifest 版本一致；后续代码交付递增补丁版本。
- 实际 Chrome 全流程和真实 LLM 新输出待验收；不将自动化模拟结果作为外部模型质量结论。

## 0.1.0

首轮实现及先前修复。此前没有随交付升级版本，从 0.1.1 开始落实版本更新记录。

## 0.1.2（2026-09-11）

- 隐藏面板版本文字，收紧顶部，并对齐双栏播放器顶部。
- 加载状态整体居中，修复图标与进度条收缩。
- 字幕抓取完成先在后台存储，多窗口合并请求；重开复用缓存，保存冲突不重复抓取。
- 统一笔记字号和图标对齐，编辑／删除靠右。
- 视频脉络增加简短总览，长视频仅提交分批摘要作最后精简；不重新发送整片逐字稿。
- 分段问题已记录为重点待确认项，本轮不修改分段规则。

## 0.1.3（2026-09-11）

视频标题上移到标题区首行，与右侧设置／收起操作顶部对齐，长标题自然换行；设置齿轮改为等间距八齿、圆角连接，按钮图标居中。仅调整展示，分段仍待确认。

## 0.1.4（2026-09-11）

按用户参考调整笔记卡片：蓝色左边线、右上角时间、灰色原文引用区、下方中文，个人理解在引用上方，疑问在下方。保留统一字体字号与图标对齐，编辑／跳转／删除靠右排列。包含 0.1.3 的标题上移及规整设置图标。


## 0.1.6 笔记图标（2026-09-11）

笔记卡片与编辑窗口共用的理解、疑问 SVG 改为用户选定的笑脸黄色灯泡与腮红粉色问号气泡。实际 Chrome 外观待用户验收。

## 0.1.5（2026-09-11）

- 面板向视频对齐改为显式位移，避免顶部外边距折叠造成位置未变化；只作用于右侧双栏。
- 中文／英文／中英改为直接切换按钮；移除当前段翻译，整片按钮简化为“LLM翻译”，保留独立阅读。
- 跟随按钮放在右下角，逻辑保持不变；导出收敛为单一入口。
- 导出弹窗支持逐字稿、笔记、视频脉络多选及 Markdown、TXT、Word DOCX、PDF。前三者本地生成下载；PDF 使用打印窗口“另存为 PDF”，不上传第三方转换。
- 删除视频脉络说明文案，简短全片总结独立展示，各主题介绍在对应卡片。旧版过长总结不再混在总览位置，提示重新整理。


## 0.1.7 纯本地逐字稿重组（2026-09-12）

- 所有新获取及生成字幕统一重组；完整句优先，向后比较组合，以英文 220／中文 100 字符为软目标，不按固定字符或秒数硬切。
- 处理常见缩写、小数、网址、引语和可靠说话人边界；当前不做音频说话人识别，不引入 SaT 或其他新依赖。
- 旧视频增加“重新分段”预览、应用和恢复；保留上次逐字稿及译文、手改段落和笔记快照，改变边界后可补齐本地翻译。正常打开仍复用缓存，不自动覆盖旧稿。
- 保存来源子串与时间映射；重叠时间定位不跳过仍有效内容；来源标识变化也显示笔记引用差异提示。
- 自动化及本地浏览器夹具结果见 test-feedback.md；真实 Chrome 的 YouTube 视频、翻译质量和播放联动待用户验收。


## 0.1.8 巨段修复与缺标点分句（2026-09-21）

- 限制短引语保护范围，修复错配引号使十几分钟文本无法断句的问题。
- 超长无标点单元增加本地分句候选与不完整短语保护，按上下文识别会话轮次，不按固定字符硬切；推断与仍偏长结果在预览中提示。
- 升级旧分段时恢复来源字符及时间范围；保留手改段、笔记、未变段译文和备份恢复。
- 三组真实稿件本地回放已通过；类型、lint、格式、109 项单元测试及构建通过。Chrome 产品交互、实际翻译和全文句子完整性仍待验收，不引入 SaT。


## 0.1.9 可修改的双快捷键（2026-09-21）

- 新增打开学习笔记的默认快捷键 Command+Shift+U／Ctrl+Shift+U，快速记笔记保留现有 Command+Shift+Y／Ctrl+Shift+Y；两者可独立修改。
- 设置页新增快捷键分类，读取实际绑定并提供 Chrome 修改入口；浏览器自动保存，返回自动刷新。删除笔记空态中的固定按键文案。
- 快捷笔记按命令分发，优先使用触发时的标签，非支持页不执行；保持草稿保存及原页面范围校验。
- 用户确认三组复测视频分段符合预期，继续本地规则，SaT 延后。类型、lint、格式、114 项单元测试与构建通过，快捷键实际 Chrome 交互待验收。
