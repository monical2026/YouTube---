# YouTube 学习笔记插件

用于在 Chrome 中阅读 YouTube 视频逐字稿、查看中文 AI 内容梳理并记录双语笔记。第一版只依据逐字稿翻译和整理，不分析视频画面；面向个人在当前电脑使用，后续再扩展多用户和跨设备能力。

插件图标采用黄橙粉渐变与白色播放符号，资源说明见 [设计文档](DOC/design.md)。

打开视频面板后自动获取字幕，中文／双语模式自动本地翻译；LLM 翻译由用户触发并直接应用无冲突结果。长视频脉络支持分批整理，快捷笔记保存后通知主面板刷新。

当前版本：**0.1.9**。本次变化见 [版本更新记录](DOC/changelog.md)。

0.1.8 修复长引号导致巨段、缺标点长段没有备用断点的问题，补充会话轮次识别和偏长提示；继续采用本地规则，不引入 SaT。旧视频点击“重新分段”预览并应用，改变边界后点击“补齐本地翻译”；可在预览窗口恢复上次逐字稿及译文。三组用户视频的分段效果已获用户确认符合预期，其他视频继续观察，详见 [修复记录](DOC/segmentation-repair-2026-09-21.md)、 [实施计划](DOC/PLAN.md) 和 [测试反馈](DOC/test-feedback.md)。

0.1.9 增加打开面板快捷键与设置页“快捷键”分类。默认打开面板为 ⌘⇧U／Ctrl+Shift+U，快速记笔记为 ⌘⇧Y／Ctrl+Shift+Y；实际绑定以设置页显示为准。点击“修改快捷键”进入 Chrome 修改并自动保存，返回时刷新显示，不依赖本机组件连接。

## 计划功能

- 原文、中文、中英双语逐字稿，支持播放高亮、自由浏览、跟随和点击跳转。
- 随 YouTube 视频切换更新内容，其他网页不注入插件界面。
- 面板关闭时快捷记笔记，支持划词摘录、后续编辑和来源版本更新提示。
- 默认中文的摘要、视频脉络、金句、方法与切片建议。
- 独立设置网页，配置 LLM、Supadata 等已适配服务及任务模型。
- 当前电脑保存，支持逐字稿和笔记导出；直接写入 Obsidian 放在后续版本。

## 安装与运行

当前使用 pnpm 11.19.0、Node.js 26.3.1（本机开发环境）、TypeScript 6.0.3、React 19.3.0、Vite 8.3.0。版本以根 `package.json` 和 `pnpm-lock.yaml` 为准。TypeScript 6 用于兼容当前 ESLint 工具链。

```sh
pnpm install --frozen-lockfile
pnpm check
```

`pnpm check` 依次执行类型、lint、格式、业务单元测试、扩展与 Swift 钥匙串组件构建。Mac 需安装可运行 `swiftc` 的命令行开发工具。检查不包含 Chrome 真实交互验收。

1. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择“加载未打包的扩展程序”，选择本项目的 `extension/dist`。
2. 复制该扩展的 ID，执行 `pnpm native:install 扩展ID`（替换最后一项）。该脚本把本机构建组件复制到当前用户的 Application Support，并仅授权这个扩展 ID，不读取或写入 API key。
3. 打开扩展的设置页，添加服务、填写 API key 和模型，选择翻译／分析／字幕对应的服务，再保存。Key 只写入 macOS 钥匙串；系统授权窗口由本人处理。
4. 刷新一个普通 YouTube 视频页，点击视频下方“学习笔记”。首次使用先获取已有字幕，再在需要时启动本地翻译。
5. 在插件“设置 → 快捷键”查看和修改“打开学习笔记”“快速记笔记”两个操作。Chrome 修改页自动保存；显示未设置时需自行指定按键。

只用已有 YouTube 字幕、本地翻译和笔记时，不需要 LLM key；Supadata 和 LLM 入口需要实际配置相应服务。没有字幕生成计价规则时不允许提交生成；每个新生成操作仍需单独确认。

本机组件当前使用注册时的 Node 可执行文件路径，适合这台开发电脑；面向其他电脑的运行时打包与签名尚未完成。源码重新构建后，需重新加载扩展，并刷新已打开的 YouTube 视频页以载入新版脚本；本机组件修改后还需再次运行登记命令。

## 验收与交付

按测试方案完成代码验证，将真实结果记录到测试反馈文档。全部适用测试通过且用户明确人工验收通过后，再执行 Git 提交及 GitHub 推送。目标仓库和可见性尚未确认。

当前凭据方案：macOS 系统钥匙串 + Native Messaging 按需组件。实现已写入，首次真实密钥保存、系统授权和重启复用仍须在产品设置页验证。

翻译策略：先采用 Chrome 本地 Translator API；`client=gtx` 保留为免费云端备选，待插件实际使用反馈后按用户指令切换。LLM 翻译主动点击才执行，本地失败不自动产生付费请求。两种免费引擎未得出整片质量或速度的对比结论。

页面范围：普通 YouTube watch 点播页；Shorts、正在直播及其他网站嵌入的播放器不属于第一版范围。
