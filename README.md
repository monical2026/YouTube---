## 安装与运行

当前使用 pnpm 11.19.0、Node.js 26.3.1（本机开发环境）、TypeScript 6.0.3、React 19.3.0、Vite 8.3.0。版本以根 `package.json` 和 `pnpm-lock.yaml` 为准。TypeScript 6 用于兼容当前 ESLint 工具链。

```sh
pnpm install --frozen-lockfile
pnpm check
```

`pnpm check` 依次执行类型、lint、格式、业务单元测试、扩展与 Swift 钥匙串组件构建。Mac 需安装可运行 `swiftc` 的命令行开发工具。检查不包含 Chrome 真实交互验收。

1. 打开 Chrome 的 `chrome://extensions`，开启开发者模式，选择“加载未打包的扩展程序”，选择本项目的 `extension/dist`。
2. 复制该扩展的 ID，执行 `pnpm native:install 扩展ID`（替换最后一项）。该脚本把本机构建组件复制到当前用户的 Application Support，并仅授权这个扩展 ID，不读取或写入 API key。
3. 打开扩展的设置页，添加服务、填写 API key 和模型，选择翻译／分析／字幕对应的服务，再保存。Key 只写入 macOS 钥匙串；系统授权窗口由本人处理。
4. 刷新一个普通 YouTube 视频页，点击视频下方“学习笔记”。首次使用先获取已有字幕，再在需要时启动本地翻译。
5. 在插件“设置 → 快捷键”查看和修改“打开学习笔记”“快速记笔记”两个操作。Chrome 修改页自动保存；显示未设置时需自行指定按键。

只用已有 YouTube 字幕、本地翻译和笔记时，不需要 LLM key；Supadata 和 LLM 入口需要实际配置相应服务。没有字幕生成计价规则时不允许提交生成；每个新生成操作仍需单独确认。

本机组件当前使用注册时的 Node 可执行文件路径，适合这台开发电脑；面向其他电脑的运行时打包与签名尚未完成。源码重新构建后，需重新加载扩展，并刷新已打开的 YouTube 视频页以载入新版脚本；本机组件修改后还需再次运行登记命令。
